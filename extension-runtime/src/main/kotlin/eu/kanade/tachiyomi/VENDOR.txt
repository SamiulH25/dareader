ADAPTED (dareader, 2026-09-15): source/model/Filter.kt nested classes
Select/Text/CheckBox/TriState/Group/Sort are `open`, not upstream's
`abstract`. 1.4-era extension bytecode instantiates them directly
(`new Filter$Text` in generated filter factories); abstract breaks linkage
with InstantiationError. Open is strictly more permissive at runtime and
remains source-compatible for 1.6 extensions that subclass them.
ADAPTED (dareader, 2026-09-16): network/PersistentCookieStore.kt reloads
preference keys verbatim; upstream mapped them through
`substringBeforeLast(".")`, so every dotted-domain cookie failed lookup and
all persisted cookies were dropped on process restart.
ADAPTED (dareader, 2026-09-16): network/NetworkHelper.kt does not clear the
source registry on user-agent changes; upstream's reset is unrepairable here
because dareader holds live source handles that nothing re-instantiates (the
reset only made `findSource(id)` return null). UA is applied per request by
UserAgentInterceptor and per source through `headersBuilder()`.
